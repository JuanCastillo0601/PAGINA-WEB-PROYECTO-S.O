Introducción

Este proyecto fue desarrollado con el propósito de integrar diferentes tecnologías utilizadas en entornos de computaciónen la nube, incluyendo virtualización, contenedores Docker y orquestación con Kubernetes.
A través de la implementación de máquinas virtuales Linux, servicios en contenedores y un clúster local con Minikube, se busca aplicar de forma práctica los conocimientosadquiridos durante el semestre y ampliarlos para comprender el funcionamiento de una arquitectura cloud básica.

Objetivos

1. Diseñar e implementar una infraestructura básica basada en virtualización, contenedores Docker y Kubernetes
2. Instalar y configurar dos máquinas virtuales Linux (server y desktop) con particionamiento manual y comunicación mediante red interna.
3. Implementar acceso remoto seguro entre las máquinas virtuales utilizando el servicio SSH.
4. Instalar y configurar Docker Engine para la creación y administración de contenedores.
5. Desarrollar y desplegar un frontend web basado en Nginx y un backend en Python utilizando Dockerfiles personalizados.
6. Orquestar los servicios mediante Docker Compose para facilitar su ejecución y administración.
7. Implementar un entorno Kubernetes con Minikube para desplegar servicios utilizando Deployment y Service.
8. Demostrar el escalado de aplicaciones mediante la creación de múltiples réplicas de un servicio en Kubernetes.
9. Documentar el proceso de implementación mediante un sitio web, capturas de pantalla, diagramas de arquitectura y un repositorio de GitHub.
